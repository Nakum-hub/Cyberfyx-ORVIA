# Regulatory Source Set

The runtime Regulatory Core must use authoritative Indian Government sources only for executable DPDP legal requirements.

Source classes include, as applicable and current at implementation time:
- Digital Personal Data Protection Act, 2023 as officially published;
- Digital Personal Data Protection Rules, 2025 as officially notified;
- official commencement notifications;
- official Gazette notifications, amendments and corrigenda;
- official MeitY notifications/directions relevant to DPDP implementation;
- official Data Protection Board materials/directions when legally relevant and authoritative for the implemented behavior.

Third-party articles, blogs, law-firm notes, social media posts, summaries, and model-generated explanations must not be treated as authoritative legal source records.

Each executable requirement record must retain sufficient metadata to identify its official source, provision/rule/schedule/notification reference, version/effective date or commencement state, applicability logic, and mapped ORVIA behavior.
