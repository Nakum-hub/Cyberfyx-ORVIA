The API integration run passed 32 assertions, including adverse and cross-tenant cases; the browser created and read back a synthetic use; and the actual monitor-worker run passed 9 assertions after the user authorized protected machine-identity setup. The monitor refuses to convert a staff-supplied OBSERVED label into independent evidence. No model or customer-data egress was added.
