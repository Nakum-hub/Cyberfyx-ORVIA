# Interface design inputs (owner, 2026-10-03)

Reference material for the planned interface redesign: colours and typography, the Cyberfyx/ORVIA logos, the shield mark
and a sign-in screen mock-up (`CyberfyxLogin.jsx`, `Cyberfyx Orvia – Sign-in preview.html`).

These files are **design references, not product code**. They are kept out of `frontend/src` so they are never built or
shipped. The mock-ups load the Montserrat font from Google Fonts; the product must not (AGENTS.md: no remote fonts or CDN
scripts). When the design is implemented, Montserrat (SIL Open Font License) is bundled locally with the application and
the logos are copied into the application's own static assets.
