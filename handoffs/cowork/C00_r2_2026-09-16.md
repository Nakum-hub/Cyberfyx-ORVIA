## Design decisions made in C00

These are open for Work and Claude Code to review.

1. **Assigned state wording adopted.** `ACKNOWLEDGED` is "Command acknowledged. Outcome not yet independently observed." `EFFECT_UNKNOWN` is "Outcome unknown. Reconciliation is required." The other assigned states follow the same pattern.
2. **Withdrawal is one action,** with the explanation shown before the button. There is no confirmation dialog and no new notice.
3. **Grant is one explicit button** shown after the notice; there is no extra checkbox. This replaces r1's dialog and checkbox as an unnecessary barrier.
4. **Receipts show stored facts.** Current progress is a separately labelled block with its own fetch time. The stored receipt is never rewritten.
5. **No `RECONCILING` or `QUARANTINED` enum.** `reconcile.pending` is only a transient button state. The quarantine display is marked UNRESOLVED (F-008).
6. **"Test Lab"** is the navigation name for regression runs.
